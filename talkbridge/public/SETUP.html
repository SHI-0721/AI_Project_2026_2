当前没有 Azure 凭据：可体验本机字幕示例和双人演示房间。演示不使用麦克风，也不是真实语音翻译。

两部安卓怎么体验？

  1. 两台手机打开同一 HTTPS 地址，选择不同语言。
  2. 第一台创建演示房间，第二台扫码加入。
  3. 第一台确认加入，点击开始。双方上方看对方、下方看自己。
  4. 任一方可暂停或结束；只有房主可继续。

此站点默认私有。第二部手机也需要获授权账号；房间码不改变站点访问权限。要邀请其他用户，需要所有者另行设置站点分享。

真实翻译需要哪些配置？

创建 Azure Speech 与 Translator 资源，将下列变量设置在服务端。不要把密钥填进网页或发到聊天里。

AZURE_SPEECH_KEY
AZURE_SPEECH_REGION
AZURE_TRANSLATOR_KEY
AZURE_TRANSLATOR_REGION

本地配置放在项目根目录 .dev.vars，然后重启。托管版本使用 Sites 运行时秘密配置，按平台要求重新部署。具体步骤和首次启动命令见项目 README.md。

页面显示“真实翻译”可用只代表配置存在，还要做实际服务连接测试。浏览器获得短期授权，长期密钥只在服务器；音频发送给 Azure Speech，文字发送给 Translator。

使用时注意什么？

  • 将房主手机放在两人之间，只有这一台开麦。
  • 轮流说普通话或日语，不依赖两人同时说话的识别效果。
  • 保持页面前台、屏幕亮着。切后台会暂停，返回后主动继续。
  • 每个房间最多30分钟。任一端离线约20秒后，下次请求触发暂停。
  • 不保存原始录音；结束立即清除字幕。超时数据在后续清理请求时删除。

验收清单

两台真实安卓，15分钟、20轮中日往返；检查数字、时间、否定、人名、重复字幕、等待时间和断线恢复。桌面模拟通过不等于实机通过。
