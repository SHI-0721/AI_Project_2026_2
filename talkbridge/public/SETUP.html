V0.7：远程双人各自开麦，双方同步原文与翻译；保留面对面、单手机和会议模式。本站公开免登录，凭房间码直接加入。

两人在不同地点：远程双人

  1. 首页选择“远程双人”，选择自己说的语言并创建对话。
  2. 朋友打开邀请链接或输入房间码，选择自己的语言。支持中、英、日、韩中的两种不同语言。
  3. 双方各自点击开麦并允许自己的麦克风；此后连续识别，不用一直按按钮。
  4. 上面看对方原文和翻译，下面看自己的话。暂停或重连仅影响自己的麦克风。

这是一场字幕对话，网站不把原声播放给对方。另开语音通话时建议戴耳机，避免对方外放声被再次录入。切后台会停止自己的麦克风，回来后手动继续；离开或结束会停止本轮双方收音。刷新恢复身份和已确认字幕，不自动开麦。

两路麦克风分别产生语音用量；不用时请暂停。仍有每房间30分钟/400条限制，尚未启用全站每月8小时硬限额。Speech资源需支持两路并发；F0官方上限为1，S0默认100，变更可能延迟生效，详见Azure配额。

V0.6 · 会议翻译与英语

打开会议翻译：听老师（英语→中文，电脑/标签页音频）；我发言（中文→英语，麦克风）。开始后在浏览器选择播放声音的会议标签页或屏幕，并勾选音频共享；没有音轨时会提示，不能识别。建议使用 Windows 桌面 Chrome/Edge。会议页允许切换标签页，关闭页面则释放采集。

播放英文前会停止采集，播完请手动开始。本机播放不等于送入会议麦克风；虚拟音频设备配置及首版限制见会议页说明。每房间仍限制30分钟/400条，停止后本页保留记录便于复制，刷新会清空。本次没有改变 Azure 资源套餐或启用月度额度限制。

一台安卓面对面使用

首页选择“单手机面对面”，或直接打开 单手机页面。选好 A、B 各自的阅读语言。手机下半屏面向 A，上半屏面向 B；上半屏默认旋转 180°，可切回正向。

每次开始、继续或重连，都由 A 先完整说一句，再由 B 说。系统使用本次连接的匿名人声标签区分双方；尚未确定的字幕单独显示，可在最终字幕中修改 A/B 归属并重新翻译。两人请轮流说话，避免同时开口。

双方的最终原文都可纠错。刷新会恢复字幕，但需手动继续收音。单机是单台设备联网使用，仍需 Azure；不保存原始录音或跨会话声纹。

两部安卓在同一地点：面对面模式

  1. 两台手机打开同一 HTTPS 地址，选择不同语言。
  2. 第一台创建对话，第二台扫码或输入房间码加入。邀请链接会标明房主语言，对方选择另一种语言。
  3. 第二人直接进入后，房主点击开始并允许麦克风。双方上方看对方、下方看自己。
  4. 任一方可暂停或结束；只有房主可继续。

站点若设置为私有，两台手机仍需获授权账号登录；所有者改为公开访问后，访客才可免 ChatGPT 登录。房间码是加入凭证，只分享给对话对象。

原文识别错了怎么办？

双手机模式：在“我说的话”中点击已完成字幕的“修改”，输入正确原文，点击“保存并重新翻译”。双方同步更新，字幕标记“已修改”。每个人只能修改自己语言的原文，不能更改发言归属语言。正在识别的临时字幕不可修改。

保存失败会保留编辑内容；重新翻译失败时，新原文仍保留，可点击“重试翻译”。演示模式的修改译文是明确标识的占位内容，不是真实翻译。

页面卡住或刷新后怎么办？

远程模式下，双方都可通过“重新连接”恢复自己的麦克风。面对面模式下，字幕停止但页面还能操作时，先点顶部“重新连接”：房主会重新建立收音连接，来宾会重新获取房间状态。仍无法恢复时点击“刷新恢复”。当前标签页会保留房间身份，重新载入后取回已确认字幕。房主需主动点击继续收音，刷新不会自动开启麦克风。不要用“离开房间”代替刷新：离开会清除本轮字幕。

V0.4：字幕响应与诊断

收音端会先显示尚在同步的原文，不必等待翻译完成。同一句最终原文与已成功翻译的临时原文相同时，直接复用该句译文。未确认同步的本机草稿不开放修改。

检测到声音但长时间没有识别活动时，页面会提示可能停更，并提供重新连接入口。环境噪声也可能触发提示；正常安静不会直接判定断线，系统不会因此自动重启麦克风。

在显示设置中展开诊断，可查看语言确认等待、翻译服务、字幕请求往返和房间查询往返耗时。这些是不同区间，不是说话到对方看到译文的总延迟；数据只在本页内存保存。

真实翻译需要哪些配置？

创建 Azure Speech 与 Translator 资源，将下列变量设置在服务端。不要把密钥填进网页或发到聊天里。

AZURE_SPEECH_KEY
AZURE_SPEECH_REGION
AZURE_TRANSLATOR_KEY
AZURE_TRANSLATOR_REGION

本地配置放在项目根目录 .dev.vars，然后重启。托管版本使用 Sites 运行时秘密配置，按平台要求重新部署。具体步骤和首次启动命令见项目 README.md。

页面显示“真实翻译”可用只代表配置存在，还要做实际服务连接测试。浏览器获得短期授权，长期密钥只在服务器；音频发送给 Azure Speech，文字发送给 Translator。

使用时注意什么？

  • 面对面模式将房主手机放在两人之间，只开这一台的麦；远程模式双方各自开麦。
  • 轮流说本房间选定的两种语言，不依赖两人同时说话的识别效果。
  • 保持页面前台、屏幕亮着。切后台会暂停，返回后主动继续。
  • 每个房间最多30分钟。远程模式某一端约20秒无心跳，只暂停该端；面对面模式会暂停整个房间。
  • 不保存原始录音；结束立即清除字幕。超时数据在后续清理请求时删除。

验收清单

两台真实安卓，15分钟、中日、中韩、日韩双向发言及原文纠错；检查数字、时间、否定、人名、重复字幕、等待时间和断线恢复。桌面模拟通过不等于实机通过。

日本語

離れた場所では「リモート2人」を選び、各自の話す言語を設定し、両端末でマイクを開始してください。自分の一時停止・再接続は相手のマイクに影響しません。共有されるのは原文と翻訳の字幕で、音声通話は行いません。以下は従来の対面モードの説明です。

音声翻訳とデモを選択できます。ルームコードで直接参加し、ホストの再承認は不要です。ホストの端末を2人の間に置き、中国語・日本語・韓国語から異なる2言語を選び、交互に話してください。相手の発言は上、自分の発言は下に表示されます。画面を開いたまま使用してください。2台モードは言語による表示分けです。1台モードでは、この接続内の匿名の話者ラベルでA/Bを区別します。開始・再接続のたびにAが先に話してください。

非公開サイトはログインが必要です。公開設定ではログインなしで利用できます。画面が止まったら上部の再読み込みからルームを復元できます。ホストは再開を押して集音してください。デモは実際の翻訳を行いません。

確定した自分の原文は「修正」から編集できます。保存後は両端末に同期され、再翻訳されます。翻訳に失敗した場合は再試行できます。デモの修正訳は例示用の表示です。
