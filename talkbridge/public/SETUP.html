V0.2：选择“真实翻译”进行中日语音交流；“演示模式”只播放示例字幕，不使用麦克风。凭房间码直接加入，无需房主二次批准。

两部安卓怎么体验？

  1. 两台手机打开同一 HTTPS 地址，选择不同语言。
  2. 第一台创建对话，第二台扫码或输入房间码加入。邀请链接会预选对方语言。
  3. 第二人直接进入后，房主点击开始并允许麦克风。双方上方看对方、下方看自己。
  4. 任一方可暂停或结束；只有房主可继续。

站点若设置为私有，两台手机仍需获授权账号登录；所有者改为公开访问后，访客才可免 ChatGPT 登录。房间码是加入凭证，只分享给对话对象。

页面卡住或刷新后怎么办？

字幕停止但页面还能操作时，先点顶部“重新连接”：房主会重新建立收音连接，来宾会重新获取房间状态。仍无法恢复时点击“刷新恢复”。当前标签页会保留房间身份，重新载入后取回已确认字幕。房主需主动点击继续收音，刷新不会自动开启麦克风。不要用“离开房间”代替刷新：离开会清除本轮字幕。

真实翻译需要哪些配置？

创建 Azure Speech 与 Translator 资源，将下列变量设置在服务端。不要把密钥填进网页或发到聊天里。

AZURE_SPEECH_KEY
AZURE_SPEECH_REGION
AZURE_TRANSLATOR_KEY
AZURE_TRANSLATOR_REGION

本地配置放在项目根目录 .dev.vars，然后重启。托管版本使用 Sites 运行时秘密配置，按平台要求重新部署。具体步骤和首次启动命令见项目 README.md。

页面显示“真实翻译”可用只代表配置存在，还要做实际服务连接测试。浏览器获得短期授权，长期密钥只在服务器；音频发送给 Azure Speech，文字发送给 Translator。

使用时注意什么？

  • 将房主手机放在两人之间，只有这一台开麦。
  • 轮流说普通话或日语，不依赖两人同时说话的识别效果。
  • 保持页面前台、屏幕亮着。切后台会暂停，返回后主动继续。
  • 每个房间最多30分钟。任一端离线约20秒后，下次请求触发暂停。
  • 不保存原始录音；结束立即清除字幕。超时数据在后续清理请求时删除。

验收清单

两台真实安卓，15分钟、20轮中日往返；检查数字、时间、否定、人名、重复字幕、等待时间和断线恢复。桌面模拟通过不等于实机通过。

日本語

音声翻訳とデモを選択できます。ルームコードで直接参加し、ホストの再承認は不要です。ホストの端末を2人の間に置き、中国語と日本語で交互に話してください。相手の発言は上、自分の発言は下に表示されます。画面を開いたまま使用してください。言語による表示分けであり、声紋による本人確認ではありません。

非公開サイトはログインが必要です。公開設定ではログインなしで利用できます。画面が止まったら上部の再読み込みからルームを復元できます。ホストは再開を押して集音してください。デモは実際の翻訳を行いません。
